PHPSandbox manual

Policy layer, not an isolation boundary. PHPSandbox executes code in the current PHP process. It does not isolate the OS, filesystem, network, CPU, memory, process, or host credentials.

PHPSandbox supports PHP 8.1 through 8.5 and PHP-Parser 5.7+. The maintained manual is Markdown so changes can be reviewed alongside code:
